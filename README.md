# Phishing Email Detection Model

## About

This project is a basic machine learning model developed as part of the
Thirenex Virtual Cyber Security Internship.

The model classifies email text as either **Phishing** or **Safe**.

## Features

- Email text classification
- Phishing and safe email dataset
- TF-IDF text feature extraction
- Logistic Regression machine learning model
- Accuracy calculation
- Confusion matrix
- User email testing

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- VS Code

## Machine Learning Process

Dataset
↓
Train/Test Split
↓
TF-IDF Feature Extraction
↓
Logistic Regression
↓
Prediction
↓
Accuracy and Confusion Matrix
